# TFT 매치 스냅샷 데이터 품질 감사 보고서 (`data_quality_check.md`)

## 1. 개요 및 배경

`output/data/match_snapshots.jsonl` 데이터셋 생성 후 등수 분포 검증 과정에서 다음과 같은 불균형이 발견되었습니다:
- **총 참가자 수**: 786명 (100개 매치 × 8명 = 800명 대비 **14명 부족**)
- **등수별 분포**:
  - 1등: 100명
  - 2등 ~ 8등: **각 98명** (등수당 정확히 2명씩 부족)

이에 따라 100개 매치 전체의 원본 Riot API 응답을 전수 조사하여 원인을 규명하고 정제 조치를 완료하였습니다.

---

## 3. 원인 분석

1. **Riot Match-V1 API 특성**:
   - 챌린저 상위 랭커의 `by-puuid` 최근 전적에 싱글 플레이어 PvE 모드(토커의 시험, Queue 1220)가 포함되어 수집되었습니다.
2. **참가자 누락 원인**:
   - `collect_match_details.py`의 봇/소환수 필터링 로직이 사람을 제외한 것이 아니라, **원본 매치 자체가 1인용 PvE 게임**이었습니다.
   - 98개 8인 매치 ($98 \times 8 = 784$명) + 2개 PvE 매치 (각 1명, 1등만 배출) = **총 786명**.
   - 따라서 1등은 $98 + 2 = 100$명, 2~8등은 각각 $98$명으로 정확히 일치하였습니다.

---

## 4. 조치 및 수정 사항

1. **`collect_match_details.py` 필터링 강화**:
   - `len(participants) != 8` 또는 `gtype == 'pve'` 또는 `qid == 1220` 인 비표준 매치는 자동으로 감지하여 건너뛰도록 필터 추가.
2. **데이터셋 정제 (`match_snapshots.jsonl`)**:
   - 문제의 2개 PvE 매치(`KR_8348606072`, `KR_8348602246`) 데이터를 제거하고 8인 표준 매치 98개만으로 재구성.
3. **단위 테스트 추가 (`test_riot_client.py`)**:
   - `test_collect_match_details_mock_filters_pve_matches`: PvE/1인 매치가 유입되어도 8인 매치만 선별 수집하는지 검증.
