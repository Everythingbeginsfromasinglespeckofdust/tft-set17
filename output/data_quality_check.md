# TFT 매치 데이터 품질 감사 및 게임 모드 정제 보고서 (`data_quality_check.md`)

## 1. 개요 및 배경

M2B(보드 상태 $	o$ 최종 등수 1~8등 예측) 모델 훈련 데이터의 무결성을 위해, 수집된 100개 매치에 포함된 게임 모드(`queueId`)별 경제/랭킹 규칙을 전수 분석하고 비표준/비랭크 모드를 제외한 **순수 표준 솔로 랭크(Queue 1100)** 데이터셋으로 정제를 완료하였습니다.

---

## 3. 세부 모드별 분석 및 제외 사유

### 1) Queue 1210 (`KR_8351881620`) 분석 결과
- **식별된 모드**: `tft_set_core_name: TFTSet16`, `tft_set_number: 16` (**Set 16 리바이벌 모드**)
- **기물 구성**: `TFT16_Vi`, `TFT16_Ambessa`, `TFT16_Leblanc`, `TFT16_Seraphine`, `TFT16_Swain` 등 Set 16 챔피언 및 시너지
- **제외 사유**: Set 17 전용 모델인 M2B에 Set 16 기물 데이터가 유입되면 기물/시너지 매핑 오류 및 심각한 데이터 오염을 유발하므로 즉시 제외.

### 2) Queue 1160 (더블업 / Pairs 20개 매치) 제외 사유
- **팀 단위 등수 및 경제 왜곡**: 2명이 1팀을 이루며 파트너 간 아이템/챔피언 지원(선물 무기고) 및 전투 지원군 메커니즘이 존재함.
- **순위 의미 차이**: 솔로 랭크의 1~8등 개인 실력/보드 파워와 더블업의 팀 순위 체계는 직접 비교가 불가능하므로 제외.

### 3) Queue 1090 (일반전 5개 매치) 제외 사유
- 경제 기본 규칙은 동일하나, 랭크 점수가 걸리지 않아 캐주얼 플레이, 실험용 빌드, 빠른 서렌더(항복) 비율이 높아 최상위 랭커 간의 진성 밸류 비교 데이터로서 노이즈가 될 수 있어 제외.

### 4) Queue 1220 (PvE 2개 매치) 제외 사유
- 1인 싱글 플레이어 모드(토커의 시험)로 1등만 배출되어 등수 분포 왜곡(1등 100명 vs 2~8등 각 98명 현상의 근본 원인)을 유발하므로 제외.
