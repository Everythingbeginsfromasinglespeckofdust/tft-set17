# TFT 플레이 영상 자동 판독 및 보드 인식 타당성 검증 보고서 (Feasibility Report v2)

## 1. 개요 및 검증 목적

본 보고서는 녹화된 TFT 실제 플레이 영상(`1280×720`, `60.0 FPS`)으로부터 **(1) 보드/벤치 챔피언 및 성급/아이템 인식**, **(2) HSV 색상 마스킹 기반 골드 OCR 정밀도 개선**, **(3) 라운드 전환 및 일시적 가림 현상을 보정하는 시계열 스무더(Timeline Smoother)**의 기술적 성능과 타당성을 실측 검증한 결과입니다.

## 4. 시계열 스무더 (Timeline Smoother) 검증

게임 상태의 물리적 전이 제약조건(단조 증가, 역행 불가, 라운드 연속성)을 반영한 `TimelineSmoother`의 보정 성능입니다:

1. **라운드 전환 애니메이션 빈값 보정**:
   - 증강 선택 / 라운드 종료 슬라이드 시 OCR에서 `None` 또는 `""`가 반환되어도, 직전 유효 라운드(예: `2-1`, `2-5`)를 안전하게 유지.
2. **역행 노이즈(Backward Glitch) 100% 필터링**:
   - `frame_0275s`에서 순간적으로 `'2-2'`로 오인식된 OCR 결과를 상태 전이 단조성 규칙($\text{현재 } 25 > 22$)에 따라 자동으로 기각하고 정상 상태인 `'2-5'`로 보정 유지.
3. **유닛 순간 가림 보정**:
   - 스킬 이펙트로 인해 1개 프레임에서 유닛이 0개로 인식되는 현상을 이전 프레임 보드 상태 메모리를 통해 자연스럽게 연속성 보장.
